# Trading Journal

A simple, mobile-friendly trading journal. Log trades, track emotions and rule-keeping, and get an automatic weekly review.

- Single file: `index.html` (HTML, Tailwind CSS compiled inline, vanilla JS)
- Data is stored in your browser (localStorage), not in this repo
- Use **Backup → Export** regularly; **Import** to restore or move devices
- Works offline

Hosted with GitHub Pages.
